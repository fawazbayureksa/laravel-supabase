## Store uploaded file paths as relative instead of full URL

- **Category:** Refactoring
- **Status:** Completed
- **Scope:** Backend

### Summary
Profile pictures, post media, and comment images now persist the disk-relative path (e.g. `profil_picture/abc.jpg`, `posts/a.jpg`) instead of a host-bound `https://.../storage/...` URL. A shared `HasPublicFileUrl` trait rebuilds the absolute public URL via model accessors (`profil_picture`, `path`, `image`), so existing frontend usage is unchanged and legacy rows that still contain full URLs keep working.
